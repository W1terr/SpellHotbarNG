Spell / item icons, spell lists and the bar frame textures come from
Spell Hotbar 2 by pWn3d1337 - https://github.com/pWn3d1337/Skyrim_SpellHotbar2

The way the selected entry of the magic / favorites menu is read follows Spell Hotbar 2 and Wheeler.

Built with CommonLibSSE-NG, the SKSE Menu Framework 3 API (QTR-Modding, LGPL-2.1) and the
Open Animation Replacer condition API by ersh1.

The item pictures (the game's Inventory3DManager drawn over two backdrops) use a technique learned from
Grid Inventory and Modex; the code is our own.
